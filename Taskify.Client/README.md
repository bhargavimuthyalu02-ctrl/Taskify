# Taskify.client

Angular client for Taskify API. Minimal scaffold.

Quick start:

1. Install Angular CLI if you don't have it:

```bash
npm install -g @angular/cli
```

2. From this folder install deps and run:

```bash
cd Taskify.Client
npm install
npm start
```

By default the client expects the API at `https://localhost:5001` or `http://localhost:5000`. Update `environment.ts` as needed.
